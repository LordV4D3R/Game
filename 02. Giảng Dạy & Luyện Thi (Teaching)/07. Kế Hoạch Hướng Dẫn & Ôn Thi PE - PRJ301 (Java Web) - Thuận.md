### 🔍 Chặng 1: Hoàn Thiện Module Search — Tìm Kiếm Đơn Hàng (4.0đ)

#### 1. Tạo Model `OrdersDto.java`
* Khai báo các trường khớp bảng `tblOrders` trong Database:
  * `orderID` (`String` - định dạng 6 chữ số `char(6)`)
  * `orderDate` (`Date` hoặc `String`)
  * `customer` (`String`)
  * `address` (`String`)
  * `totalAmount` (`long` hoặc `double`)
  * `status` (`int`: 0: Mới tạo, 1: Đang giao, 2: Đã giao, 3: Đã hủy)
* Sinh đầy đủ Constructor không tham số, Constructor đầy đủ tham số, và Getters/Setters.

#### 2. Xây dựng DAO `OrdersDao.java`
* Viết hàm tìm kiếm theo địa chỉ (Address):
  ```java
  public List<OrdersDto> searchByAddress(String keyword) throws ClassNotFoundException, SQLException
  ```
* **⚠️ BẪY ĐIỂM QUAN TRỌNG:**
  * Câu SQL phải dùng tìm kiếm tương đối: `WHERE address LIKE ?`
  * **Đặc biệt (Đề mục 2.3):** Chỉ hiển thị đơn có trạng thái **không phải reject** (`status != 3`):
    $$\text{SQL: } \text{SELECT ... FROM tblOrders WHERE address LIKE ? AND status != 3}$$
  * Tham số truyền vào: `ps.setString(1, "%" + keyword + "%")`.

#### 3. Bổ sung Action `search` trong `MainController.java`
* **Bảo vệ quyền truy cập (Đề mục 2.1):** Kiểm tra `session.getAttribute("LOGIN_USER") == null` $\rightarrow$ đá về `login.jsp`.
* Lấy tham số: `String txtSearch = request.getParameter("txtSearch")`.
* **⚠️ BẪY ĐIỂM (Đề mục 2.2):** Nếu người dùng không nhập gì vào ô search (`txtSearch == null || txtSearch.trim().isEmpty()`) và bấm Search $\rightarrow$ **KHÔNG hiển thị bảng kết quả**.
* Nếu có nhập `txtSearch`:
  * Gọi `OrdersDao.searchByAddress(txtSearch)`.
  * **⚠️ BẪY ĐIỂM (Đề mục 2.5):** Tính tổng `TotalAmount` của toàn bộ đơn hàng trong kết quả tìm được.
  * Nếu danh sách rỗng: gán thông báo lỗi `"No data matching the search criteria found !"`.
  * Lưu vào request: `listOrders`, `totalAmount`, `txtSearch` (để giữ lại từ khóa trong ô nhập), `errorMessage`.
  * Forward sang trang hiển thị kết quả tìm kiếm (`search.jsp`).

#### 4. Xây dựng Giao diện `search.jsp` (Dùng JSTL / EL)
* Thêm taglib JSTL core: `<%@taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core"%>`.
* Kiểm tra session ở đầu trang: `<c:if test="${empty sessionScope.LOGIN_USER}"><c:redirect url="login.jsp"/></c:if>`.
* Giữ từ khóa tìm kiếm: `<input type="text" name="txtSearch" value="${param.txtSearch}"/>`.
* Hiển thị bảng kết quả: Dùng `<c:forEach items="${listOrders}" var="o" varStatus="counter">`.
* Các cột: `No.`, `OrderID`, `Order date`, `Customer`, `Address`, `TotalAmount`, `Status`, `Action`.
* **⚠️ BẪY ĐIỂM CỰC LỚN (Đề mục 2.4):**
  * Nút "Update" chỉ được xuất hiện với đơn chưa giao.
  * Đơn hàng có trạng thái **Delivered (`status == 2`) KHÔNG ĐƯỢC PHÉP Update** $\rightarrow$ ô Action để trống:
    ```jsp
    <td>
        <c:if test="${o.status != 2}">
            <a href="MainController?action=update&orderID=${o.orderID}">Update</a>
        </c:if>
    </td>
    ```
* **Chân bảng (Footer):** Hiển thị tổng tiền: `Total : ${totalAmount}`.
* Báo lỗi đỏ nếu không có bản ghi nào: `<c:if test="${not empty errorMessage}"><p style="color:red">${errorMessage}</p></c:if>`.

### ✏️ Chặng 2: Hoàn Thiện Module Update — Cập Nhật Đơn Hàng (2.5đ)

#### 1. Viết hàm hỗ trợ trong `OrdersDao.java`
* Hàm lấy chi tiết 1 đơn hàng theo ID (để nạp vào form sửa):
  ```java
  public OrdersDto getOrderByID(String orderID) throws ClassNotFoundException, SQLException
  ```
* Hàm cập nhật đơn hàng:
  ```java
  public boolean updateOrder(OrdersDto order) throws ClassNotFoundException, SQLException
  ```
  Câu lệnh: `UPDATE tblOrders SET orderDate=?, customer=?, address=?, totalAmount=?, status=? WHERE orderID=?`.

#### 2. Xử lý Action trong `MainController.java`
* **Action `update` (khi click nút Update từ bảng):**
  * Lấy `orderID`, gọi `OrdersDao.getOrderByID(orderID)`.
  * Đưa đối tượng tìm được vào `request.setAttribute("ORDER_DETAIL", order)`.
  * Forward sang `update.jsp`.
* **Action `saveUpdate` (khi nhấn "Save to database" trên form):**
  * Lấy các trường: `orderID`, `orderDate`, `customer`, `address`, `totalAmount`, `status`.
  * Validate ràng buộc dữ liệu (không được để trống, đúng định dạng số).
  * Gọi `OrdersDao.updateOrder(...)`.
  * Sau khi update thành công (Đề mục 3.4): Refresh lại lưới dữ liệu với bản ghi mới nhất từ DB.

#### 3. Xây dựng Giao diện `update.jsp`
* Bảo vệ session chống truy cập trực tiếp.
* Form nạp dữ liệu cũ của đơn hàng:
  * `orderID`: Để chế độ `readonly="readonly"` (khóa không cho sửa khóa chính).
  * `orderDate`, `customer`, `address`, `totalAmount`, `status`: Cho phép chỉnh sửa.
* Nút submit đặt tên: `Save to database`.
