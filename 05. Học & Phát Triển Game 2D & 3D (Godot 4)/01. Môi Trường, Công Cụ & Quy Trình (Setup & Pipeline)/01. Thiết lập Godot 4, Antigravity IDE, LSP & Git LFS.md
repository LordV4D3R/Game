## 🔌 Sơ Đồ Kết Nối Giữa Godot 4 Editor & Antigravity IDE

Khi làm việc với GDScript, bạn dùng **Godot 4 Editor** để dựng cảnh (Scene/Node) và dùng **Antigravity IDE** để viết code cùng AI Agent. Hai phần mềm giao tiếp thời gian thực qua giao thức **LSP (Language Server Protocol)** và **DAP (Debug Adapter Protocol)**:

```mermaid

    subgraph Antigravity["Antigravity IDE (Code Workspace)"]
        Ext["Extension: godot-tools (geequlim)"]
        Err["Extension: Error Lens"]
        Git["Extension: GitLens + Git LFS"]

    end

    subgraph GodotEditor["Godot Engine 4.x Editor"]

    Ext <-->|"Tự động gợi ý hàm & Báo lỗi cú pháp"| LSP
    Ext <-->|"Đặt Breakpoint & Debug trực tiếp"| DAP
    AI -->|"Đọc/Ghi file .gd & .tres"| Scene
```

## ⚙️ Cấu Hình Chi Tiết Từng Công Cụ

### Cấu Hình Extensions Bắt Buộc Trên Antigravity IDE
- **`godot-tools` (tác giả: geequlim):**
  - Mở Settings của Antigravity IDE (`Ctrl + ,`) $\rightarrow$ tìm `Godot Tools`.
  - Tại mục `Godot_tools > Editor_path: Godot4`: Trỏ đường dẫn tới file thực thi `Godot_v4.x-stable_win64.exe` trên máy của bạn.
  - Tại mục `Godot_tools > Gdscript_lsp: Server_port`: Đặt là `6005` (khớp với mặc định của Godot 4.x).
- **`Error Lens`:** Hiển thị ngay lỗi thiếu dấu hai chấm `:`, sai kiểu dữ liệu (Static Typing) của GDScript ngay trên dòng code.
- **`GitLens`:** Giúp bạn xem lịch sử từng dòng code GDScript ai sửa (bạn hay AI sửa) và đối chiếu các commit.
- **`Markdown All in One`:** Hỗ trợ xem và chỉnh sửa các file tài liệu `.md` trong Obsidian mượt mà.

### Cấu Hình Bên Trong Godot 4 Editor
- Vào menu **Editor $\rightarrow$ Editor Settings $\rightarrow$ Text Editor $\rightarrow$ External**:
  - Bật **Use External Editor**: `On` (hoặc tắt nếu bạn muốn đôi lúc mở nhanh script trong Godot, nhưng vẫn giữ LSP hoạt động).
- Vào **Editor $\rightarrow$ Editor Settings $\rightarrow$ Network $\rightarrow$ Language Server**:
  - Đảm bảo **Remote Port** là `6005` và bật **Enable Smart Resolve**.

## 📦 Cấu Hình Git + Git LFS Cho Dự Án Game (Chống Phình Dung Lượng Repo)

Game chứa rất nhiều file nhị phân nặng (ảnh `.png`, nhạc `.ogg`/`.wav`, mô hình 3D `.glb`/`.blend`). Nếu chỉ dùng Git thường, repo sẽ bị phình to và chậm. **Git LFS (Large File Storage)** là bắt buộc:

### Mẫu Tệp `.gitignore` Chuẩn Cho Godot 4
```gitignore
# Godot 4+ specific ignores
.godot/
.nomedia

# Exported builds
build/
exports/
*.exe
*.pck

# OS / Editor temporary files
.DS_Store
Thumbs.db
*.tmp
*~
```

### Mẫu Tệp `.gitattributes` Chuẩn Cho Git LFS (Đồ Họa, Âm Thanh, 3D)
```gitattributes
# Đồ họa 2D & Nguồn thiết kế
*.png filter=lfs diff=lfs merge=lfs -text
*.jpg filter=lfs diff=lfs merge=lfs -text
*.webp filter=lfs diff=lfs merge=lfs -text
*.aseprite filter=lfs diff=lfs merge=lfs -text
*.kra filter=lfs diff=lfs merge=lfs -text
*.psd filter=lfs diff=lfs merge=lfs -text

# Âm nhạc (OST/BGM) & Hiệu ứng âm thanh (SFX)
*.ogg filter=lfs diff=lfs merge=lfs -text
*.wav filter=lfs diff=lfs merge=lfs -text
*.mp3 filter=lfs diff=lfs merge=lfs -text

# Đồ họa 3D & Mô hình
*.glb filter=lfs diff=lfs merge=lfs -text
*.gltf filter=lfs diff=lfs merge=lfs -text
*.fbx filter=lfs diff=lfs merge=lfs -text
*.blend filter=lfs diff=lfs merge=lfs -text
```

- [ ] **`[Code cùng AI]`** Cài đặt đủ 4 extensions trên Antigravity IDE: `godot-tools` (geequlim), `Error Lens`, `GitLens`, `Markdown All in One` và kết nối thành công cổng LSP `6005` (báo trạng thái *Connected* ở thanh dưới cùng IDE).
- [ ] **`[Code cùng AI]`** Nhờ AI khởi tạo `git init`, cài đặt `git lfs install`, tạo tệp `.gitignore` và `.gitattributes` chuẩn cho Godot 4 + Git LFS.
- [ ] **`[Code cùng AI]`** Mở **GitHub Desktop**, thêm Local Repository vừa tạo để trực quan hóa các thay đổi của cả file code lẫn file hình ảnh/âm thanh.
- [ ] **`[Code cùng AI]`** Viết thử 1 file `logger.gd` (Autoload) chuẩn hóa các hàm ghi log (`info`, `debug`, `warn`, `error`) để áp dụng xuyên suốt dự án theo đúng quy chuẩn `GEMINI.md`.
